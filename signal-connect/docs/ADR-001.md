# ADR 001 — isolated Execution 01 foundation

Standalone Next.js 16.1.0 / React 19.2.3 / TypeScript, matching the website runtime. Exact versions and package-lock make installation reproducible. No new runtime library or service. Framework, lint, browser and accessibility tooling mirror the repository and are pinned to its lockfile.

Brand adapter copies the two canonical brand modules byte-for-byte from main c68d966, with equality tests. Tokens are extracted from canonical @theme and checked for parity. A minimal CSS utility bridge supports the unchanged logo classes without importing website layout or Tailwind. Inter uses next/font/google with the canonical latin/optional configuration: font requests occur at build time, font files are served locally at runtime. No fallback font is substituted to make a blocked build pass.

Public company inbox sales@signalone.co.za comes from app/lib/site.ts. No private founder phone/email assumed. vCard identifies Andisiwe as Founder and labels the shared inbox WORK.

Execution 01 reserves a clearly labelled, non-scannable QR area. No QR dependency is introduced until Execution 02, when a local encoder and immutable HTTPS visitor origin must be selected and documented. Visitor skeleton has no form, submission endpoint, analytics or success state. Story and manufacturer assets remain in the canonical repository for Execution 03; no fictional founder photo is used.

Deploy target is a new separate Vercel project rooted at signal-connect. Never alter existing production project configuration or deploy a placeholder publicly. A protected preview requires validation; Sites publication is production and is therefore not an alternative to that preview gate.

Service worker caches only public presenter/contact/icon URLs and same-origin hashed static assets. It ignores RSC requests, all writes and other routes, uses versioned caches and removes only older Signal Connect caches. First-load asset caching and installed update behavior require browser evidence before release.

Test tool resolution required an explicit playwright-core 1.56.1 dev dependency: npm otherwise selected a newer peer for axe, producing incompatible Page types. It is pinned to the existing Playwright runner version. Root TypeScript/ESLint exclude signal-connect to preserve independent builds; no marketing route or style changes. Managed preview supplies Vite flags, so scripts/dev.mjs translates the launch into Next's supported host/port arguments.
